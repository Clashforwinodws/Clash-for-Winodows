📌 版本概览：v0.20.39 的历史坐标

2023 年 9 月，Clash for Windows 的主仓库转为只读，开发者 Fndroid 宣布停止维护。随后发布的 v0.20.39 成为该项目的最后正式版本。它并非功能大爆炸的更新，而是一次精准的“收尾”——修复了数个安全隐患，增强了 TUN 驱动兼容性，并优化了与 Clash.Meta 内核的协同工作。

在代理工具快速迭代的今天，v0.20.39 仍然被许多用户视为“稳定的代名词”。理解这个版本的每个细节，不仅能帮助旧用户安全地留守，更是向 CFW 历史 致敬的最佳方式。

💡 版本信息： 发布于 2023 年底，安装包大小约 85 MB，支持 Windows 7 及以上系统，内核兼容 Clash 和 Clash.Meta。

🔒 安全修复：TLS 证书验证与 CVE

v0.20.39 最关键的变更之一是修复了 TLS 证书验证绕过漏洞（CVE-2023-XXXX）。在之前的版本中，当用户开启“跳过证书验证”选项时，客户端的内部 API 调用也错误地受到了影响，导致即使未勾选该选项，某些情况下证书校验仍不严格。

该版本重新隔离了用户配置的“跳过验证”与系统内部请求，确保只有用户明确指定的代理连接才会忽略证书错误。同时，内置的 CA 证书库得到了更新，减少了因证书过期导致的 x509: certificate has expired 错误。

# 此前版本中，以下配置可能导致 API 通信也跳过验证
skip-cert-verify: true

# v0.20.39 修复后，仅对出站代理生效，内部 API 始终保持严格验证

这一修复虽小，但显著提升了整体安全性，尤其是在使用公共 Wi‑Fi 或不可信网络时。如果你仍在运行旧版 CFW，这是升级的最强理由之一。

🌐 TUN 驱动优化：告别 Wintun 冲突

v0.20.39 针对 TUN 模式进行了若干底层优化，主要涉及 Wintun 驱动的加载逻辑。此前，当系统中存在多个 TUN 接口（例如同时安装了 CFW 和 Clash Verge Rev）时，Wintun 驱动可能因竞争资源而导致“创建设备失败”错误。

新版本改进了驱动安装检测机制：如果发现相同版本的 Wintun DLL 已被其他程序加载，CFW 会复用现有驱动实例，而不是尝试重复安装。这减少了因驱动冲突导致的蓝屏或断网风险。

然而，这并未完全解决 cfw-tun 残留网卡 的问题。许多用户从 CFW 迁移后，旧网卡仍然出现在设备管理器中。彻底清理的方法我们已在 《Windows TUN 驱动深度解析》 中详细说明，强烈建议旧用户阅读。

此外，v0.20.39 还调整了 TUN 模式下的 auto-route 策略，使路由表修改更精确，避免了与 Hyper‑V 虚拟交换机的冲突。

🧩 规则引擎微调与内核兼容性

虽然规则引擎的核心逻辑没有大幅改动，但 v0.20.39 修复了一个长期存在的 bug：当使用 RULE-SET 引用外部规则集时，如果规则文件包含 BOM 头或尾随空格，会导致部分规则匹配失败。新版本增强了 YAML 解析器的容错性。

同时，该版本完整支持了 Clash.Meta v1.16.0 及以下内核的新特性，包括 AND/OR 逻辑规则、PROTOCOL 匹配器等。这意味着即使在 CFW 停止更新后，用户依然可以手动替换核心文件来获得新协议支持。

关于如何利用这些高级规则编写更高效的分流策略，请参阅 《如何编写高效的自定义代理规则》 以及 《策略组完全解析》。

🔄 升级与迁移：如何平稳切换到新生态

v0.20.39 虽稳定，但已不再接收安全更新。我们建议大多数用户迁移到活跃维护的 Clash Verge Rev。以下是平滑迁移的关键步骤：

  1. 备份现有配置： 导出 CFW 的 config.yaml 和所有 provider 文件。
  2. 清理残留驱动： 按照 驱动清理指南 彻底删除 cfw-tun 网卡和注册表项。
  3. 安装 Clash Verge Rev： 从 下载中心 获取最新版，首次启动时选择 Clash.Meta 内核。
  4. 适配配置文件： 大部分 CFW 配置可直接导入，但需注意策略组语法差异。详细的模块化管理可参考 《大型配置文件管理指南》。
  5. 验证网络： 依次测试系统代理、TUN 模式、DNS 解析，确保功能正常。

如果你选择继续使用 v0.20.39，请务必关闭“自动更新”，并从可信来源下载安装包。我们仍在 下载中心 提供该版本，但仅作为过渡方案。

❔ 常见问题：旧版用户的最后疑问

Q：v0.20.39 还能用多久？

理论上可以一直使用，但随着操作系统更新（如 Windows 12 未来版本），可能会出现兼容性问题。建议最晚在 2027 年前完成迁移。

Q：为什么我的 v0.20.39 偶尔崩溃？

通常是 TUN 驱动与系统更新冲突导致。尝试在设置中切换为“系统代理”模式，或更新 Wintun DLL 文件。详见 常见问题页面。

Q：CFW 配置可以直接导入 Clash Verge Rev 吗？

大部分情况下可以，但某些 UI 配置（如窗口位置、主题）会丢失。代理节点和规则部分完全兼容。首次导入后建议进行 TUN 模式优化 以确保最佳体验。

🏁 结语：一个版本的终章，一个时代的序曲

v0.20.39 是 Clash for Windows 的“毕业答卷”，它用一场稳重的更新为项目画上了句号。在它之后，代理客户端进入了百花齐放的新阶段——Clash Verge Rev、FlClash、Clash Nyanpasu 等工具接过了接力棒，而 Clash.Meta 内核则继续演化，支持着越来越复杂的协议和规则。

作为用户，我们或许会怀念 CFW 简洁的界面和熟悉的托盘图标，但技术的进步从不等待。本文连同 《CFW 背后的故事》 和 《透视 CFW 内部》，希望能为你留住这段开源历史，并帮助你在新的代理世界继续畅行无阻。
